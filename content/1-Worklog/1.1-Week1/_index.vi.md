### Kết quả đạt được tuần 1:

* Làm quen với môi trường thực tập và các thành viên trong First Cloud AI Journey (FCAJ).

* Hiểu và nắm được các nội quy, quy định cần tuân thủ trong quá trình thực tập.

* Hiểu AWS là gì, vai trò của điện toán đám mây và nắm được các nhóm dịch vụ AWS cơ bản:

  * Compute
  * Storage
  * Networking
  * Database
  * Security & Identity
  * Monitoring & Management
  * Developer Tools / DevOps
  * AI & Machine Learning
  * Analytics
  * Application Integration

* Đã tạo và thiết lập AWS Free Tier account, đồng thời làm quen với các cấu hình cơ bản của tài khoản AWS.

* Làm quen với AWS Management Console và biết cách:

  * Đăng nhập vào AWS.
  * Tìm kiếm các dịch vụ AWS.
  * Truy cập và quản lý tài nguyên thông qua giao diện web.
  * Kiểm tra thông tin cơ bản của các dịch vụ đang sử dụng.

* Cài đặt và cấu hình AWS CLI trên máy tính, bao gồm:

  * Access Key
  * Secret Access Key
  * Default Region
  * Default Output Format

* Sử dụng AWS CLI để thực hiện một số thao tác cơ bản như:

  * Kiểm tra thông tin tài khoản AWS.
  * Kiểm tra cấu hình AWS CLI.
  * Xem danh sách Region.
  * Tìm hiểu và thao tác với dịch vụ EC2.
  * Tạo và quản lý Key Pair.
  * Kiểm tra thông tin các tài nguyên AWS.

* Tìm hiểu những kiến thức cơ bản về Amazon EC2, bao gồm:

  * Khái niệm EC2 Instance.
  * Các loại EC2 Instance và mục đích sử dụng.
  * AMI (Amazon Machine Image).
  * EBS (Elastic Block Store).
  * Security Group.
  * Các phương thức kết nối SSH đến EC2.
  * Elastic IP và mục đích sử dụng địa chỉ IP tĩnh.

* Hiểu được mối liên hệ cơ bản giữa:

  * AMI
  * EC2 Instance
  * EBS
  * Security Group
  * Elastic IP

  trong quá trình khởi tạo, kết nối và quản lý một máy chủ trên AWS.

* Phân biệt được hai phương thức quản lý tài nguyên AWS:

  * **AWS Management Console:** quản lý tài nguyên thông qua giao diện web.
  * **AWS CLI:** quản lý tài nguyên thông qua giao diện dòng lệnh.

* Có thể bước đầu kết hợp AWS Management Console và AWS CLI để kiểm tra và quản lý tài nguyên AWS.

* Hình thành kiến thức nền tảng về AWS, làm cơ sở để tiếp tục tìm hiểu các dịch vụ chuyên sâu và thực hiện các bài thực hành trong những tuần tiếp theo.

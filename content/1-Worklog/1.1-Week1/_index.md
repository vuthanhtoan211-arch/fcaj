### Week 1 Achievements:

* **Familiarity with the FCAJ internship environment:**
  * Understood the organization's rules and internship guidelines.
  * Learned how to organize tasks, maintain Worklogs, and monitor learning progress.
  * Became familiar with team members and the overall internship learning approach.

* **Understanding of Cloud Computing fundamentals:**
  * Understood cloud computing concepts and their differences from traditional infrastructure.
  * Distinguished between IaaS, PaaS, and SaaS.
  * Learned about scalability, flexibility, cost optimization, and high availability.
  * Gained basic knowledge of AWS Global Infrastructure, including Regions, Availability Zones, and Edge Locations.

* **Understanding of major AWS service categories:**
  * **Compute:** Amazon EC2, AWS Lambda.
  * **Storage:** Amazon S3, Amazon EBS.
  * **Networking:** Amazon VPC, Elastic Load Balancing.
  * **Database:** Amazon RDS, Amazon DynamoDB.
  * **Security & Identity:** AWS IAM.
  * **Monitoring & Management:** Amazon CloudWatch.
  * **Developer Tools / DevOps:** AWS CodeBuild, AWS CodePipeline.
  * **Analytics:** AWS Glue, Amazon Athena.
  * **AI & Machine Learning:** Amazon SageMaker.
  * **Application Integration:** Amazon SQS, Amazon SNS.

* **Familiarity with the AWS Management Console:**
  * Learned how to sign in and navigate AWS services.
  * Understood how to locate services and select the appropriate AWS Region.
  * Learned how the console is used to create, manage, and monitor cloud resources.
  * Became familiar with basic account information and service management interfaces.

* **Introduction to AWS CLI:**
  * Understood the purpose of managing AWS resources through command-line tools.
  * Studied AWS CLI installation on Windows.
  * Learned the structure of CLI credentials, default Region, and output format settings.
  * Practiced basic commands for checking the AWS CLI version and configuration.
  * Understood the differences between AWS Management Console and AWS CLI workflows.
  * Recognized the importance of protecting AWS credentials and keeping them out of source code repositories.

* **Knowledge of Amazon EC2 fundamentals:**
  * Understood the purpose of EC2 Instances and virtual servers.
  * Distinguished between Instance Types, AMIs, and EBS volumes.
  * Learned how Security Groups control inbound and outbound network traffic.
  * Studied SSH connections and EC2 Key Pairs.
  * Understood Public IP, Private IP, and Elastic IP concepts.
  * Learned how EC2 Instances, AMIs, EBS, Security Groups, and IP addresses work together.

* **Awareness of AWS security and cost management:**
  * Understood that AWS Free Tier is subject to eligibility requirements and usage limits.
  * Recognized that AWS resources may incur charges depending on service configuration and consumption.
  * Learned about IAM and the Principle of Least Privilege.
  * Understood the importance of reviewing resources and monitoring AWS Billing.

* **Initial direction for the internship project:**
  * Identified the main technology areas relevant to developing a student activity management web application.
  * Understood the roles of Frontend, Backend, Database, Storage, and Monitoring within a cloud architecture.
  * Established the foundation needed to analyze requirements, propose an architecture, and develop the **Student Activity Management & Engagement Analytics Platform** during subsequent weeks.

### Challenges and Lessons Learned:

* The AWS ecosystem contains many services with different purposes. Categorizing services by functionality makes them easier to understand and evaluate.
* AWS Management Console and AWS CLI provide different workflows; learning both improves overall cloud resource management skills.
* AWS usage requires attention to technical implementation, security, access control, and cost management.
* Before choosing cloud services or provisioning resources, it is important to understand the business problem and system requirements.

### Plan for Next Week:

* Analyze the student activity management problem.
* Define project objectives, scope, and user roles.
* Identify Registration, Attendance, and Evidence data sources.
* Establish business rules for Check-in/Check-out and participation reconciliation.
* Research and propose an AWS architecture that fits the project's requirements and budget.

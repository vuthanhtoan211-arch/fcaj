### Week 1 Achievements:

* Became familiar with the internship environment and the members of First Cloud AI Journey (FCAJ).

* Understood the basic rules and regulations that must be followed during the internship.

* Gained a basic understanding of AWS, the role of cloud computing, and the main categories of AWS services, including:

  * Compute
  * Storage
  * Networking
  * Database
  * Security & Identity
  * Monitoring & Management
  * Developer Tools / DevOps
  * AI & Machine Learning
  * Analytics
  * Application Integration

* Created and configured an AWS Free Tier account and became familiar with the basic AWS account settings.

* Became familiar with AWS Management Console and learned how to:

  * Sign in to AWS.
  * Search for AWS services.
  * Access and manage AWS resources through the web interface.
  * Check basic information about AWS services and resources.

* Installed and configured AWS CLI on the local computer, including:

  * Access Key
  * Secret Access Key
  * Default Region
  * Default Output Format

* Used AWS CLI to perform several basic operations, such as:

  * Checking AWS account information.
  * Checking AWS CLI configuration.
  * Viewing the list of AWS Regions.
  * Exploring and interacting with Amazon EC2.
  * Creating and managing Key Pairs.
  * Checking information about AWS resources.

* Learned the fundamentals of Amazon EC2, including:

  * The concept of an EC2 Instance.
  * EC2 Instance Types and their use cases.
  * AMI (Amazon Machine Image).
  * EBS (Elastic Block Store).
  * Security Groups.
  * Methods for connecting to an EC2 instance using SSH.
  * Elastic IP and the purpose of using a static public IP address.

* Understood the basic relationship between:

  * AMI
  * EC2 Instance
  * EBS
  * Security Group
  * Elastic IP

  when launching, connecting to, and managing a virtual server on AWS.

* Understood the differences between the two main methods of managing AWS resources:

  * **AWS Management Console:** Managing AWS resources through a web-based graphical interface.
  * **AWS CLI:** Managing AWS resources through the command-line interface.

* Became capable of using both AWS Management Console and AWS CLI to perform basic AWS resource management and verification tasks.

* Built a foundational understanding of AWS, which will support further study of advanced AWS services and hands-on exercises in the following weeks.

## Worklog

Throughout the internship program, I completed **12 weeks** of work, starting with learning the fundamentals of AWS and its core services, followed by system analysis and design, application development, AWS deployment, data processing and analytics, system testing, documentation, demonstration, and final project completion.

The main project developed during the internship was:

**Student Activity Management and Engagement Analytics Platform**

The system was designed to support the management, reconciliation, and analysis of student participation data for university activities. During the project, I gradually applied AWS services such as Amazon Cognito, Amazon API Gateway, AWS Lambda, Amazon DynamoDB, Amazon S3, AWS Glue, Amazon Athena, Amazon QuickSight, Amazon CloudWatch, and AWS Amplify.

The work completed during each week is summarized below:

**Week 1:** [Getting familiar with AWS and its core services](1.1-week1/)

**Week 2:** [Analyzing the problem, defining requirements, and designing the system architecture](1.2-week2/)

**Week 3:** [Developing core functions and testing in the local environment](1.3-week3/)

**Week 4:** [Deploying the backend with API Gateway, Lambda, DynamoDB, and Amazon S3](1.4-week4/)

**Week 5:** [Developing the frontend, implementing authentication with Amazon Cognito, and deploying with AWS Amplify](1.5-week5/)

**Week 6:** [Building the data processing pipeline, exporting results, and preparing analytics data](1.6-week6/)

**Week 7:** [Building the Analytics Dashboard, configuring monitoring, and performing system integration testing](1.7-week7/)

**Week 8:** [Performing system, security, performance, and UAT testing and optimizing AWS resources](1.8-week8/)

**Week 9:** [Completing technical documentation, User Guide, Test Report, and Demo preparation](1.9-week9/)

**Week 10:** [Finalizing the system, Workshop, Demo, and project results](1.10-week10/)

**Week 11:** [Presenting the Demo, collecting feedback, applying final improvements, and preparing project handover](1.11-week11/)

**Week 12:** [Completing the internship report, archiving the project, reviewing AWS resources, and concluding the internship](1.12-week12/)

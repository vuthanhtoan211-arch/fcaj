## Worklog

Throughout the internship program at **First Cloud AI Journey (FCAJ)**, I followed a structured learning, research, and project development plan over **12 weeks**, from **September 7, 2026, to November 27, 2026**.

The internship began with learning the fundamentals of Cloud Computing and AWS, becoming familiar with core AWS services, analyzing project requirements, and designing the system architecture. The subsequent stages focused on Backend development, Frontend development, database implementation, data processing, AWS service integration, system testing, Demo application deployment, and technical documentation.

The main project developed during the internship was:

**Student Activity Management & Engagement Analytics Platform**

The system was designed to support the management, tracking, reconciliation, and analysis of student participation data in university activities. The project focuses on addressing challenges related to consolidating student registration data, attendance records, participation evidence, and activity participation confirmation.

The application was developed using **React/Vite** for the Frontend, **Python/FastAPI** for the Backend, and **SQLite** as the database for the MVP version. The system supports two main user roles, **ADMIN** and **STUDENT**, with features for activity management, student account management, registration data import, real-time Check-in/Check-out, evidence import, data reconciliation, participation confirmation, data analytics, and report export.

Throughout the project, I gradually researched, experimented with, and integrated **six AWS services** within a scope appropriate to the system:

* **AWS Amplify:** Deploying and hosting the Frontend of the Web Application.
* **Amazon DynamoDB:** Researching and testing a NoSQL database within the AWS Data Pilot.
* **Amazon S3:** Storing data, CSV files, and data processing results.
* **AWS IAM:** Managing access permissions and execution permissions for AWS resources.
* **AWS Lambda:** Developing a CSV file processing workflow as a Serverless Demo.
* **Amazon CloudWatch:** Monitoring execution logs, processing results, and Lambda metrics.

In addition to application development, I also studied REST APIs, Authentication, Authorization, Data Processing, Data Analytics, Serverless Architecture, Git/GitHub, software testing, data security, AWS cost management, and application deployment in Cloud environments.

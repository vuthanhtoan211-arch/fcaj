# Events Participated

During my internship in the **First Cloud AI Journey (FCAJ)** program, I had the opportunity to participate in two technology events related to Amazon Web Services (AWS), Cloud Computing, Artificial Intelligence, and modern software development.

These events provided valuable opportunities to expand my technical knowledge, explore emerging technology trends, and learn from experienced professionals and members of the technology community.

More importantly, the knowledge gained from these events helped me develop a broader understanding of how AWS technologies could be applied to my internship project, **Student Activity Management & Engagement Analytics Platform**.

---

## [4.1. Event 1 – AWS Cloud & AI Day Vietnam 2026 – Watch Party](4.1-Event1/)

### Event Information

- **Event Name:** AWS Cloud & AI Day Vietnam 2026 – Watch Party
- **Date:** September 29, 2026
- **Format:** Watch Party – Technical sessions and community networking
- **Role:** Attendee

### Event Overview

The event focused on emerging trends in Cloud Computing and Artificial Intelligence, particularly how organizations and businesses can leverage AWS technologies to develop modern applications and intelligent systems.

The main topics I explored included:

- Current trends in Cloud Computing and Artificial Intelligence.
- Generative AI and Agentic AI.
- Building applications that integrate Cloud technologies and AI capabilities.
- Data Analytics and the importance of Data Engineering.
- Application modernization using AWS.
- Security, scalability, and cloud cost optimization.

### Knowledge and Outcomes

Through the event, I gained a better understanding of the role of Cloud Computing in designing, deploying, and operating modern software systems.

I also realized that applying AI to real-world applications requires more than machine learning models. It depends on reliable data infrastructure, appropriate system architectures, and effective data processing workflows.

These lessons were particularly relevant to my Student Activity Management & Engagement Analytics Platform project, which includes student registration processing, attendance tracking, evidence reconciliation, analytics, and reporting.

The event also strengthened my interest in pursuing a career in **Cloud Computing and Data Engineering**.

## [4.2. Event 2 – AWS First Cloud AI Journey Community Day 2026](4.2-Event2/)

### Event Information

- **Event Name:** AWS First Cloud AI Journey Community Day 2026
- **Date:** Saturday, October 31, 2026
- **Time:** 09:00 AM – 12:00 PM
- **Venue:** Bitexco Financial Tower
- **Address:** 02 Hai Trieu Street, Sai Gon Ward, Ho Chi Minh City, Vietnam
- **Format:** In-person event
- **Role:** FCAJ Learner / Student Attendee

### Event Overview

AWS First Cloud AI Journey Community Day 2026 was a technical community event designed to share practical experiences and knowledge with students and individuals interested in AWS technologies.

The event featured several technical and career development sessions:

1. **Lessons Learned from Building Software Factories**
2. **Education**
3. **AWS Lambda Web Functions: Rethinking Serverless Web Architecture**
4. **Amazon SQS: Building Asynchronous Systems**
5. **My 3-Month AWS Internship Journey**
6. **Start & Maintain Consistency with Open Source Contributing**

These sessions introduced important concepts related to Serverless Architecture, asynchronous processing, software development practices, internship experiences, and Open Source contribution.

### Knowledge and Outcomes

One of the most valuable topics I learned about was the use of AWS Lambda for Serverless applications and data processing workflows.

This knowledge was closely related to the CSV processing experiment in my Student Activity Management & Engagement Analytics Platform project, which involved Amazon S3, AWS Lambda, AWS IAM, and Amazon CloudWatch.

Additionally, the Amazon SQS session helped me understand asynchronous system architectures and the importance of decoupling components to improve scalability.

Beyond technical knowledge, the sessions on AWS internships and Open Source highlighted the importance of continuous learning, hands-on practice, and source code management using GitHub.

Participating in these two technology events provided valuable learning experiences throughout my First Cloud AI Journey internship.

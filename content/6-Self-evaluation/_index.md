## Internship Self-Assessment

During my participation in the **First Cloud AI Journey (FCAJ) – AWS Study Group** internship and learning program, I had the opportunity to explore the field of **Cloud Computing**, learn about Amazon Web Services (AWS), and apply the knowledge acquired at university to a practical project.

With an academic background in **Data Science**, I considered this internship an opportunity to expand my knowledge beyond data analysis and processing into system development, application deployment, and cloud resource management.

Throughout the internship, I focused on learning and practicing AWS services such as **Amazon DynamoDB, Amazon S3, AWS Lambda, AWS Amplify Hosting, AWS Identity and Access Management (IAM), and Amazon CloudWatch**. I also strengthened my technical skills in Python, FastAPI, React/Vite, REST APIs, GitHub, and other software development tools.

One of my main responsibilities was developing the **Student Activity Management & Engagement Analytics Platform**, a system designed to manage university activities and analyze student participation. Through this project, I gained practical experience in Backend development, Frontend development, registration and attendance processing, evidence reconciliation, analytics, and application deployment in a Demo environment.

In addition to technical knowledge, I improved my self-learning ability, documentation skills, requirements analysis, debugging techniques, and task management through weekly Worklogs.

Regarding my work ethic, I consistently tried to organize my tasks effectively, proactively research unfamiliar topics, and incorporate feedback to improve the quality of my work.

However, I also recognized areas that require further improvement, including practical system deployment experience, advanced problem-solving skills, technical communication, and time management.

To reflect objectively on my internship experience, I would like to assess myself using the following criteria:

### 1. Strengths and Achievements

**Expanded Technical Knowledge**

Through the internship, I gained valuable experience learning and practicing important AWS services. Previously, my academic knowledge mainly focused on Data Science, data processing, and specialized university subjects. After the internship, I developed a better understanding of how to organize a Web Application architecture integrated with Cloud services.

Developing the Student Activity Management & Engagement Analytics Platform allowed me to combine programming, data management, API development, and application deployment within a practical system.

**Self-Learning and Research Skills**

I improved my ability to independently explore AWS Documentation, understand new services, and apply technical knowledge through hands-on exercises.

When encountering issues involving the Backend, Frontend, authentication, APIs, or AWS integration, I practiced identifying root causes, investigating individual components, and selecting appropriate solutions.

**System Development Thinking**

Working on the project helped me better understand the relationships between different application components.

I practiced workflows involving data collection, business processing, storage, reconciliation, analytics, and report generation. These experiences highlighted the importance of proper data structures and consistency across system features.

**Testing and Debugging Skills**

During development, I encountered and addressed various issues related to API connectivity, user authentication, authorization, data processing, and deployment configuration.

These experiences encouraged me to review actual results, interpret error messages, investigate causes, and perform verification after making changes.

**Technical Documentation and Reporting**

By preparing weekly Worklogs, writing bilingual Workshop documentation, and recording AWS exercises, I improved my ability to present technical information in a structured and understandable manner.

I also recognized that clear documentation supports project maintenance, testing, and future development.

### 2. Areas for Improvement

Despite the progress I made, several areas still require further development.

* **Advanced Cloud Computing Knowledge:** I need to deepen my understanding of Production architectures, Networking, Security, CI/CD, Monitoring, and AWS resource optimization. Although I have practiced integrating several services, I still need more experience with larger and more complex systems.

* **Problem-Solving Skills:** Complex issues involving multiple application components sometimes require considerable investigation time. I need to improve my debugging methodology, develop more structured Test Cases, and strengthen my Log analysis skills.

* **Discipline and Time Management:** I need to improve task estimation, prioritization, and time allocation between research, programming, testing, and documentation.

* **Technical Communication:** I should become more confident when presenting technical solutions, sharing ideas, and explaining complex problems. I also need to continue improving my English communication skills in professional IT environments.

* **Practical Deployment Experience:** The current project primarily serves educational and demonstration purposes. I need to gain more experience in scalability, security, performance optimization, Cloud Backend deployment, and Production system operations.

### 3. Personal Development Plan

After the internship, I have identified several goals for continued professional development:

1. **Strengthen AWS Knowledge:** Continue studying AWS services, particularly Networking, Compute, Storage, Database, and Security.

2. **Improve Python and Data Processing Skills:** Develop stronger capabilities in data processing, API development, SQL, and tools relevant to Data Engineering.

3. **Explore Cloud Architecture and Data Engineering:** Study ETL/ELT workflows, Data Pipelines, Data Warehouses, and Cloud-based data processing architectures.

4. **Continue Developing Practical Projects:** Improve the Student Activity Management & Engagement Analytics Platform, especially Cloud Backend deployment, system optimization, and advanced analytics functionality.

5. **Enhance Soft Skills:** Practice communication, teamwork, time management, and technical presentations in English.

### 4. Overall Assessment

Overall, I would rate my internship performance as **Good**.

Although several areas still require improvement, I have gained valuable technical knowledge and practical experience, particularly in Cloud Computing, Web Application development, and data processing.

The internship helped me better understand how university knowledge can be applied to a structured development project, from requirements analysis and system design to implementation, testing, deployment, and documentation.

This experience provides an important foundation for my long-term career goal of becoming a **Data Engineer / Cloud & Data Engineer**.

I will continue learning proactively, addressing my weaknesses, and improving my ability to apply technical knowledge to practical projects.

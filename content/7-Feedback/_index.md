## 7.1. Overall Evaluation of the First Cloud AI Journey Experience

### 1. Learning and Working Environment

During my participation in the First Cloud AI Journey (FCAJ) program, I had the opportunity to explore a learning environment focused on cloud computing technologies provided by Amazon Web Services (AWS). The program encouraged me to independently study technical documentation, explore new technologies, and apply theoretical knowledge to practical projects.

One of the aspects I appreciated most was the combination of theoretical learning and hands-on practice. Instead of only studying cloud computing concepts, I gradually designed, developed, and tested the Student Activity Management & Engagement Analytics Platform, covering Backend development, Frontend implementation, data processing, and the deployment of selected components on AWS.

Throughout the development process, I encountered challenges involving environment configuration, component integration, debugging, and AWS service management. However, these challenges helped me improve my ability to research technical problems, identify root causes, and develop systematic solutions.

### 2. Support from Mentors and the FCAJ Community

During my learning journey, the technical documentation, Workshop materials, and learning resources provided by the AWS Study Group community played an important role in helping me understand unfamiliar AWS services.

I particularly appreciated the program's emphasis on independent learning, practical experimentation, and project-based development rather than passive theoretical study. Researching documentation, verifying configurations, and resolving technical issues helped me develop stronger self-learning habits.

I also found that practical examples and detailed, step-by-step instructions were especially valuable for students who were new to AWS.

For future programs, I hope more learning materials will cover real-world system architectures, security best practices, cloud deployment, monitoring, and cost optimization.

### 3. Relevance of the Project to My Academic Major

As a student majoring in Data Science, I found that the Student Activity Management & Engagement Analytics Platform was closely related to the knowledge and skills I had acquired at university.

The project focuses on student activity data management, registration processing, attendance tracking, evidence collection, data reconciliation, and participation analytics.

These functions allowed me to apply data processing concepts, database design principles, and analytical thinking to a practical management problem.

In addition to strengthening my academic knowledge, the project helped me explore software engineering technologies such as Python, FastAPI, React, JavaScript, and RESTful APIs.

More importantly, working with Amazon S3, AWS Lambda, Amazon DynamoDB, Amazon CloudWatch, AWS IAM, and AWS Amplify helped me better understand the connection between Data Engineering, Software Engineering, and Cloud Computing.

### 4. Learning Opportunities and Technical Skill Development

Throughout the project, I gained valuable experience in several technical areas.

**Backend Development:** I practiced building RESTful APIs using FastAPI, implementing authentication and role-based authorization, and managing student activities, registrations, and attendance records.

**Frontend Development:** I used React and Vite to develop a web interface, integrate APIs, and implement features for two user roles: ADMIN and STUDENT.

**Data Processing:** I worked with CSV/XLSX imports, registration data validation, real-time Check-in/Check-out records, participation evidence, data reconciliation, and analytical reporting.

**AWS Cloud Services:** I gained practical exposure to several AWS services:

- Amazon S3 for object storage and data organization.
- AWS Lambda for experimenting with serverless CSV processing.
- Amazon DynamoDB for exploring NoSQL data storage.
- AWS IAM for access control and resource permissions.
- Amazon CloudWatch for monitoring application execution logs.
- AWS Amplify for deploying the Frontend application to the Cloud.

Beyond technical skills, the project also helped me improve my planning, documentation, testing, troubleshooting, and technical English reading skills.

Maintaining Worklogs and Workshop documentation allowed me to track progress, review completed tasks, and better understand the overall development process.

### 5. Project Development Experience and Personal Initiative

One of the most valuable parts of this experience was independently developing a system consisting of multiple interconnected components.

During the initial development stage, I faced challenges in database design, API organization, and Frontend implementation.

When integrating the Frontend with the Backend, I had to troubleshoot issues involving API configuration, authentication, authorization, and Cross-Origin Resource Sharing (CORS).

Later, experimenting with AWS Lambda, Amazon S3, DynamoDB, and Amplify helped me understand the differences between developing an application locally and deploying selected components in a cloud environment.

These experiences showed me that software development involves much more than writing code. It also requires architecture design, testing, monitoring, security considerations, resource management, and technical documentation.

Although the project still has certain limitations, particularly because the Backend primarily operates in a local Demo environment and the full application has not been migrated to AWS, the development process gave me a more realistic understanding of the application lifecycle.

### 6. Learning Resources and AWS Cost Management

I appreciated the availability of AWS services that allow students to explore cloud architectures and develop practical applications.

However, working with AWS also helped me recognize the importance of cloud cost management.

Students must understand which resources are running, monitor service usage, review configurations, and clean up unnecessary resources after completing their experiments.

During the project, I reviewed the AWS resources that had been used, examined CloudWatch logs, and planned the clean-up process following the completion of the system Demo.

I believe future FCAJ learning materials could place additional emphasis on AWS Free Tier, Cost Explorer, billing alerts, and practical cost management strategies to help students use cloud services more confidently and responsibly.

## 7.2. Most Satisfying Aspects of the Internship

The most satisfying part of my experience was being able to transform theoretical knowledge into a functional software project.

Through the Student Activity Management & Engagement Analytics Platform, I experienced multiple stages of application development, including requirements analysis, data modeling, Backend development, Frontend implementation, API integration, testing, deployment, and technical reporting.

In particular, implementing student activity management, attendance tracking, evidence processing, data reconciliation, and reporting functions helped me understand how data-driven systems can support real-world administrative processes.

I also found the troubleshooting process rewarding. Each technical issue I resolved contributed to a more stable application and strengthened my confidence in handling practical development challenges.

## 7.3. Areas for Improvement

Despite the positive experience, I would like to offer several suggestions that could help improve future FCAJ programs.

First, the program could provide more end-to-end Workshops that guide students through the complete lifecycle of a project, from system design and development to deployment, monitoring, and optimization.

Second, more practical examples demonstrating how to integrate Frontend applications, Backend services, databases, and AWS resources would help students understand real-world cloud application architectures.

Third, security, AWS IAM best practices, cost monitoring, and resource clean-up should be emphasized throughout the learning process rather than being introduced only at the end.

Finally, additional sessions covering real-world engineering experiences, project case studies, and career opportunities in Cloud Engineering, Data Engineering, and Cloud & Data Engineering would be especially valuable for students preparing to enter the technology industry.

## 7.4. Would I Recommend FCAJ to Other Students?

I would recommend the First Cloud AI Journey program to students who are interested in Cloud Computing, AWS, Software Development, or Data Engineering.

In my opinion, the program provides a valuable opportunity to explore technologies beyond traditional university coursework and gain practical experience with widely used cloud services.

However, students should be prepared to learn independently, read technical documentation, experiment with different solutions, and remain persistent when facing technical challenges.

These habits are essential for making meaningful progress throughout the program.

## 7.5. Suggestions and Future Expectations

After completing the program and my project, I would like to continue developing my knowledge and skills in Cloud Computing and Data Engineering.

My future learning objectives include:

- Improving my Backend development and system architecture skills.
- Exploring Amazon S3, AWS Lambda, DynamoDB, and other AWS data processing services in greater depth.
- Learning about ETL/ELT processes and data pipeline development.
- Deploying Backend applications to cloud infrastructure instead of relying primarily on local environments.
- Strengthening my knowledge of cloud security, monitoring, and cost optimization.
- Exploring Infrastructure as Code, CI/CD, and deployment automation.
- Continuing to improve the Student Activity Management & Engagement Analytics Platform with a focus on scalability and practical deployment.

If opportunities are available, I would be interested in participating in additional AWS-related Workshops, learning activities, or practical engineering projects.

## 7.6. Final Reflection

The First Cloud AI Journey program provided me with a valuable opportunity to explore cloud computing and gradually apply technical knowledge to a practical software project.

By developing the Student Activity Management & Engagement Analytics Platform, I strengthened my understanding of programming and data processing while learning how different AWS services can support application development.

Although there are still areas that require further study and improvement, the experience has helped me better understand my interests and long-term career direction in Cloud Computing and Data Engineering.

I sincerely appreciate the First Cloud AI Journey program and the AWS Study Group community for providing useful technical resources, learning opportunities, and practical guidance that have supported my professional development.
